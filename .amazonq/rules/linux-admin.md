# linux-admin project rule

Treat `AGENTS.md` as the main repository instruction source.

For Linux administration work, read `skills/using-linux-admin/SKILL.md` first when the specialist is unclear. Load only the selected `skills/<skill-name>/SKILL.md` and required chunks; do not duplicate or preload the full 103-skill tree.

Always follow `docs/UNIVERSAL_SKILL_EXECUTION_CONTRACT.md`. Use `docs/SECURITY_PATCH_REFRESH_POLICY.md` for version-sensitive OS guidance. Start with bounded read-only evidence, keep changes scoped, prepare rollback before risky operations, validate results, and never invent repository state, global paths, or command outcomes.
