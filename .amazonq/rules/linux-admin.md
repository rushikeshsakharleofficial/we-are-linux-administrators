# linux-admin project rule

Treat `AGENTS.md` as the main repository instruction source.

For Linux administration work, select the smallest relevant file under `skills/<skill-name>/SKILL.md` and read only the required chunks.

Always follow `docs/UNIVERSAL_SKILL_EXECUTION_CONTRACT.md`. Use `docs/SECURITY_PATCH_REFRESH_POLICY.md` for version-sensitive OS guidance. Start with bounded read-only evidence, keep changes scoped, prepare rollback before risky operations, validate results, and never invent repository state or command outcomes.
